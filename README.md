# Texas Hold'em Odds Engine

A C++17 Monte Carlo simulator that plays out **10 million poker hands in ~0.2 seconds** to estimate the win odds of any starting hand. Every hand is stored as a **single 64-bit integer**, and odds for all **169 distinct starting hands** (against 1–9 opponents) are precomputed into an 18 KB table, so preflop lookups take a few nanoseconds.

## Performance

Measured on a 2-core cloud VM with GCC 13, `-O3 -march=native`:

| | |
|---|---|
| Simulation | 10M hands in **0.19 s** on 2 threads, **0.41 s** single-threaded (~50M hands/s) |
| Preflop lookup | **~7 ns** per lookup; the 169 × 9 table is 18,252 bytes |
| Memory per hand | **8 B**, vs 20 B for a 5-card `int32` list and 28 B for 7 cards |
| Evaluator correctness | Exhaustively verified on all **133,784,560** seven-card hands |

## How it works

### 1. One hand = one `uint64_t`

Each of the 52 cards is one bit. The layout is suit-major, with each suit in its own 16-bit lane:

```text
 63        48 47        32 31        16 15         0
 [  spades   ][  hearts   ][ diamonds  ][   clubs   ]     bit = suit*16 + rank
   ---AKQJT98765432 (13 bits used per lane)               rank 0 = '2' ... 12 = 'A'
```

Adding a card is `hand |= card`, testing is `hand & card`, and a suit's ranks are `(hand >> 16*suit) & 0x1FFF`. Hole cards, board and full 7-card hands are all the same 8-byte type — no vectors, no heap, no sorting.

### 2. Bitwise 7-card evaluator ([`evaluator.hpp`](include/holdem/evaluator.hpp))

From the four 13-bit suit lanes `c, d, h, s` the evaluator derives, with no loops:

```cpp
any        = c | d | h | s;                                // ranks present
two_plus   = (c & d) | (h & s) | ((c | d) & (h | s));      // ranks paired or better
three_plus = (c & d & (h | s)) | (h & s & (c | d));        // ranks tripped or better
four       = c & d & h & s;                                // quads
```

Flushes come from a popcount per lane; straights and "keep the top N ranks" come from five 8 KB tables built at **compile time** (`constexpr`). The result is a 32-bit value — category in the top bits, rank masks below — so comparing two hands is one integer comparison.

The test suite checks this against known totals for **all 2,598,960 five-card hands**, the **7,462 distinct hand strengths**, and **all 133,784,560 seven-card hands** (that last one runs in about a second).

### 3. Monte Carlo simulator ([`simulator.cpp`](src/simulator.cpp))

- The remaining deck is an array of one-hot `uint64_t`s; each trial does a **partial Fisher–Yates** shuffle of only the cards it needs (board + opponents' hole cards). The deck is never reset — a permuted deck is still a valid start.
- Random numbers come from **xoshiro256\*\*** with Lemire's multiply-shift for bounded ranges.
- Work is split across `std::thread`s, each with its own independently seeded RNG, so there's no shared state or locking.
- Ties are scored as fractional pot shares (`equity = wins + Σ 1/(k+1)` for k-way splits).

### 4. Precomputed 169-hand table ([`preflop.hpp`](include/holdem/preflop.hpp))

The 1,326 two-card combos reduce to 169 classes (13 pairs, 78 suited, 78 offsuit), laid out on the standard 13×13 grid. `starting_hand_index()` maps any two-card `uint64_t` to its cell with a few bit operations, and the lookup is a single array read.

The table ([`src/preflop_table.inc`](src/preflop_table.inc), also exported as [`data/preflop_odds.csv`](data/preflop_odds.csv)) was generated by `tools/precompute.cpp` with **10M trials per hand heads-up** and **2M per hand for 2–9 opponents** — about 4.4 billion simulated hands in under 4 minutes. Heads-up standard error is about ±0.015 percentage points.

## Memory comparison

| Representation | 5 cards | 7 cards | 64-bit saves |
|---|---|---|---|
| `uint64_t` bitmask (this project) | 8 B | 8 B | — |
| `int32` per card (Cactus Kev style) | 20 B | 28 B | 60% / 71% |
| `struct { int rank; int suit; }` per card | 40 B | 56 B | 80% / 86% |
| `std::vector<int32>` (24 B header + heap) | 44 B | 52 B | 82% / 85% |


## Library use

```cpp
#include "holdem/simulator.hpp"
#include "holdem/preflop.hpp"

using namespace holdem;

Hand hero = *parse_hand("As Kd");
float eq = preflop_odds(hero, /*opponents=*/3).equity;   // instant

SimConfig cfg;
cfg.hero = hero;
cfg.board = *parse_hand("Ah 7c 2d");
cfg.opponents = 2;
SimResult r = simulate(cfg);                              // 10M hands
printf("%.2f%%\n", 100 * r.equity());
```

Link against the `holdem` CMake target.
